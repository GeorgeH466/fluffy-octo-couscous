# cyberdeck-arsenal OUI database (MAC address vendor prefixes)
# =============================================================================
# Format : AA:BB:CC Vendor name
# Used by : lib/cyberlib.py (OuiLookup), wifi_probe_logger.py, ble_scanner.py,
#           arp_mapper.py, network_map.py, rogue_ap_detector.py
#
# This file is a curated seed so the suite works out of the box and offline.
# Replace it with the full IEEE registry (~35k entries) with:
#
#     cdeck update          # or
#     curl -sL https://standards-oui.ieee.org/oui/oui.txt -o /tmp/oui.txt
#     awk '/\(hex\)/ {gsub(/\(hex\)/,""); print $1, substr($0, index($0,$4))}' \
#         /tmp/oui.txt > /opt/cyberdeck-arsenal/data/oui_database.txt
#
# Locally-administered (randomised) MACs are detected by the U/L bit in the
# first octet and are reported as "Randomised (locally administered)" rather
# than being looked up here - modern phones rotate their MAC for every network.
# =============================================================================
